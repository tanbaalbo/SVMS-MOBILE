승하선 순번 — 아이폰에서 쓰기

사파리에서 SVMS에 로그인한 뒤 북마크 한 번으로 순번표를 띄웁니다. 처음 한 번만 아래 설정을 하면 됩니다. (2026.10.30)

① 북마크 코드 복사

복사가 안 되면 아래 칸을 길게 눌러 "전체 선택" → "복사"

② 북마크 만들기 (사파리)

1
이 페이지에서 아래 공유 버튼(네모에 화살표) → 북마크 추가 → 이름을 승하선 순번으로 바꾸고 저장
2
사파리 아래 책 모양(북마크) → 오른쪽 아래 편집 → 방금 만든 승하선 순번 누르기
3
주소 칸의 내용을 전부 지우고, ①에서 복사한 코드를 붙여넣기 → 완료

주소가 javascript:(function(){… 로 시작하면 된 것입니다. (SVMS 모바일 보기 북마크를 만들 때와 같은 방법)

③ 쓰는 법

1
사파리에서 svms.sinokor.co.kr 에 로그인 (비밀번호는 아이폰 키체인 자동 완성)
2
북마크 승하선 순번을 누르면 그 탭에 순번표가 뜹니다. 처음이면 SVMS에서 불러오기로 명단을 만듭니다 (1~2분).
3
그다음부터는 로그인 → 북마크만 누르면 됩니다. SVMS 업데이트로 최신 명단을 받고, 교대 등록·순서 바꾸기·연락처도 안드로이드 앱과 같습니다.

명단은 이 아이폰의 사파리(SVMS 사이트 저장소)에만 남습니다. SVMS에 7일 넘게 안 들어가면 사파리가 지울 수 있는데, 그때는 SVMS에서 불러오기로 다시 만들면 됩니다(교대 등록·바꾼 순서는 다시 넣어야 함).

④ 인터넷 없이 보기 (선택)

1
승하선 순번 보기 페이지를 열고 공유 → 홈 화면에 추가
2
순번표(③)에서 SVMS 업데이트 → 오프라인 보기용 복사
3
홈 화면의 승하선 순번 앱을 열고 붙여넣기로 가져오기 (붙여넣기 허용을 물으면 허용)

보기 전용입니다. 새로 받을 때마다 2·3을 다시 하면 됩니다.
