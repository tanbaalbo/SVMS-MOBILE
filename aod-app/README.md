# SVMS AOD (갤럭시 탭 S12 Ultra용)

태블릿을 켜 두는 동안 검은 화면에 시계·선박 정보·당직·SVMS 화면을 띄우는 안드로이드 앱입니다.

## 보여주는 것

- 큰 시계: 선박 시간(UTC + 시차) 또는 태블릿 시간, 날짜·요일
- UTC 시간, 선박 이름·항차, 다음 항구·ETA, 메모 한 줄
- 당직: 지금 당직(2/O·C/O·3/O), 교대까지 남은 시간과 진행 바, 내 당직까지 남은 시간
- 배터리 (픽셀 테마는 하트 10개)
- SVMS 패널(선택): 로그인해 둔 SVMS 화면을 옆(가로) 또는 아래(세로)에 띄우고 정해진 간격으로 새로고침. `svms-mobile.js`로 좁은 화면 배치, 어둡게 뒤집기 적용

테마: 기본 / 택티컬 레드(발로란트 느낌) / 픽셀 블록(마인크래프트 느낌) / 레이더(항해 녹색)

## 설치

1. GitHub 저장소의 **Actions → AOD 앱 빌드** 에서 최근 실행을 열고 `svms-aod-apk`를 받습니다.
   (main 브랜치에 합쳐진 뒤에는 Releases의 `aod-latest`에서 `svms-aod.apk`를 바로 받을 수 있습니다.)
2. 압축을 풀고 `svms-aod.apk`를 누릅니다. "출처를 알 수 없는 앱" 설치를 허용합니다.
3. 같은 키로 서명하므로 새 버전은 지우지 않고 덮어 설치됩니다.

## 쓰는 법

- 앱을 열면 설정 화면입니다. 선박 정보·시차·내 당직·테마를 넣고 **AOD 켜기**를 누릅니다.
- AOD 화면은 시계 부분을 **두 번 탭**하면 닫힙니다.
- **화면 꺼지면 자동으로 AOD**를 켜면, 화면이 꺼질 때마다(시간 초과·전원 버튼) AOD가 뜹니다.
  - 처음 켤 때 **다른 앱 위에 표시** 권한을 허용해야 합니다. **배터리 최적화에서 빼기**도 해 두면 삼성 절전 기능이 대기 서비스를 끄지 않습니다.
  - 대기하는 동안 알림줄에 "AOD 대기 중" 알림이 떠 있습니다. 안드로이드에서 뒤에서 계속 기다리려면 꼭 필요한 알림입니다.
  - AOD가 떠 있을 때 전원 버튼을 누르면 AOD를 다시 띄우지 않고 화면이 완전히 꺼집니다.
  - 충전 중이 아니고 배터리가 정한 값(기본 20%) 이하이면 AOD가 꺼지고 다시 뜨지 않습니다.
  - 잠금 화면 위에 뜬 AOD에서는 SVMS 패널을 만질 수 없습니다(보기만 가능).
  - 삼성 기본 AOD는 꺼 두세요. 둘 다 켜져 있으면 겹칠 수 있습니다.
- 충전할 때만 켜지게 하려면 자동 켜기 대신 **화면 보호기로 설정** → 화면 보호기에서 `SVMS AOD`를 고릅니다.
- SVMS 새로고침은 **자동 새로고침** 스위치로 끌 수 있습니다.
- SVMS를 띄우려면 **SVMS 로그인**에서 한 번 로그인한 뒤 **SVMS 화면 표시**를 켭니다.

## 참고

- 삼성 기본 AOD(화면이 완전히 꺼진 상태)를 대신할 수는 없습니다. 이 앱은 화면을 아주 어둡게 켜 둔 채 보여주는 방식이라 배터리를 쓰므로 충전 중에 쓰는 것을 권합니다.
- 번인 방지를 켜 두면 1분마다 화면 전체가 조금씩 움직입니다.
- 화면 내용은 1분에 한 번만 다시 그리지만, 패널은 내용이 그대로여도 주사율(최대 120Hz)만큼 계속 화면을 내보냅니다. 그래서 AOD가 떠 있는 동안 패널이 지원하는 가장 낮은 주사율을 요청합니다. 실제로 얼마까지 내려가는지는 패널에 달려 있습니다.
